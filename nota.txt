ESTRUTURA GERAL DO PROGRAMA


MENU PRINCIPAL
1 - Cadastro (Usuario)
2 - Login (Usuario)
0 - Sair
admin - Acesso administrador


CADASTRO (USUARIO)
- Usuario informa: nome, email e senha
- Regras:
    - Email deve conter "@", "gmail" e ".com"
    - Senha precisa ter no minimo 4 digitos
- Dados sao salvos na lista "usuarios"
- Tudo em minusculo (.lower())


LOGIN (USUARIO)
- Usuario informa nome e senha
- Sistema verifica se o nome e senha correspondem
- Se correto: entra no menu do usuario
- Se errado: mensagem "Usuario nao encontrado"


MENU USUARIO LOGADO
1 - Buscar Produtos
2 - Agendar Servicos
3 - Carrinho
0 - Sair


BUSCAR PRODUTOS
- Mostra todos os produtos com:
      numero, nome, estoque e preco
- Usuario escolhe o produto pelo numero
- Informa quantidade desejada
- Se confirmado, adiciona ao carrinho e reduz estoque


AGENDAR SERVICOS
- Mostra lista de servicos:
      1 - Tosa     R$xx
      2 - Banho    R$xx
      3 - Exame    R$xx
- Usuario escolhe o servico
- Servico e adicionado ao carrinho


CARRINHO
- Mostra todos os itens adicionados (produtos e servicos)
- Mostra o total da compra
- Se confirmar pagamento:
      -> Limpa o carrinho
      -> Finaliza sessao


MENU ADMINISTRADOR
LOGIN ADMIN:
  email: admin@gmail.com
  senha: admin


MENU ADMIN
1 - Usuarios
2 - Produtos
3 - Servicos
0 - Sair


ADMIN / USUARIOS
1 - Adicionar usuario
2 - Remover usuario
3 - Listar usuarios


ADMIN / PRODUTOS
1 - Adicionar produto
2 - Remover produto
3 - Atualizar estoque/preco


ADMIN / SERVICOS
1 - Adicionar servico
2 - Remover servico
3 - Gerenciar datas
